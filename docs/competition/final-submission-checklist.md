## Evidence / claims gate

Before submission verify the deck/demo never says:
- [ ] “landslide probability” for Climate Stress;
- [ ] “people saved/protected” for benefit proxy;
- [ ] “COP recommendation” while optimizer uses planning credits;
- [ ] “drainage capacity” for corridor proxy;
- [ ] “exact current population” for detailed DANE proxy;
- [ ] “exact Pareto frontier” for sampled non-dominated set;
- [ ] “probability of optimality” for selection stability;
- [ ] “we replace SIATA.”

## City-scale screen claims

Allowed:
- official 2026 population projection;
- official 2023 IMCV/AMPI;
- official hazard coverage;
- explicit Exposure / Balanced / Equity lenses;
- 248/249 safe population matches;
- Llanaditas #7 exposure / #13 balanced / #22 equity.

Required limitation:
- population-within-barrio hazard exposure assumes uniform distribution;
- IMCV component is comuna-level.

## AI story

Must show the AI/decision engine doing something visible:
- [ ] generate four robust policy options;
- [ ] show lower-tail P10;
- [ ] switch objective profile and change project portfolio;
- [ ] show “Why here?” explanation;
- [ ] show policy consensus/disagreement;
- [ ] show uncertainty/budget/stability/trade-offs.

Do not let the demo become “look at our 3D map.”

## Climate context and optional station comparison

Ourea ships a complete observed climate context from CHIRPS v3 Final. Do not present a waiting state.

- [x] Observed climate context is CHIRPS v3 Final, climatology 1991–2020;
- [x] Typical / high / extreme presets are observational percentiles, not arbitrary millimetres;
- [x] Every visible climate figure includes source, period and accumulation window;
- [x] Copy states that Ourea supports planning decisions and does not issue real-time forecasts;
- [x] SIATA is optional local-intensity comparison, not a runtime dependency and not a missing feature.

Every slide should help answer at least one judging question:
- Is it relevant?
- Is it innovative?
- Is the potential impact concrete?
- Is it understandable?
- Can it be piloted?
